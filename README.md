### Проверка

1. Оба участника используют одинаковые версии игры и мода, разные Steam-аккаунты.
2. Полностью закройте игру, запустите установщик и выберите папку с Selkie.exe. Сохранённый пакет восстанавливается кнопкой удаления в этом же установщике.
3. Запустите игру через Steam и загрузите мир в одинаковом месте.
4. Хост нажимает F6, второй игрок — F7 и выбирает комнату. F8 отключает соединение.
5. Проверьте появление комнаты, подключение и движение голубых капсул. При ошибке приложите статусы с обоих экранов.

Пока синхронизируются только позиции игроков. Предметы, лодка и прогресс независимы; голоса нет. Реальное подключение двух Steam-аккаунтов ещё требует подтверждения. Noclip сохранён: F2 — полёт, F3 — возврат.

Установка и удаление проверены на тестовой папке с побайтовым восстановлением файлов, включая чужой резерв. Сам установщик не содержит полную игру. Для работы нужна приобретённая игра.
